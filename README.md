One original line: a one-star review of Monday, written as though Monday were a restaurant — a forty-minute wait, cold coffee, a waiter blaming the kitchen, and a bill that cost the whole weekend. The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks it against the gate (UTF-8, 1–180 characters, not only white space, a single line of at most 25 words) before finishing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
